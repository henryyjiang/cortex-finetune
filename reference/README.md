# External reference data

Numbers produced by other people, kept because the project compares against them.
Nothing here is ours and nothing here is regenerated by our code.

## `olmo_50k_steps.jsonl`

McLeish's benchmark ladder for the OLMo-2 retrofits — the models this project forked its recipe
from. Recovered 2026-09-14 from `paper_plots/data/` before that directory was deleted (blob
`bf9e9b0195b8db27ad3944f433aba7e20c216a94`); it was nearly lost because it is named like a loss
curve and is not one.

2,400 rows, one per (model, checkpoint, eval recurrence, task):

| field | meaning |
|---|---|
| `model` | `4,6,4 75 sqrt (Train Recurrence=N)` for N in {4, 8, 16, 32}, plus `Olmo-2-step1907359 Static Depth` |
| `chkpt` | training step, 1,000 … 48,000 (× 1,048,576 tokens/step) |
| `task` | `gsm8k_cot_sean` (flexible-extract) or `minerva_math` |
| `num_rec` | recurrence used at EVAL, 1 … 32 |
| `train_rec` | recurrence the model was trained at |
| `acc`, `stderr` | accuracy and its standard error |
| `effective_params`, `FLOPs` | the paper's `(6·N1 + 2·N2)·D` accounting |

**Why it matters.** `train_rec=8` is cortex's exact configuration — same base, same (4,6,4)
arrangement, same optimizer and LR — so it is the only token-matched external reference the GSM8K
question has:

| tokens | McLeish train-rec 8, eval-rec 8 | cortex |
|---|---|---|
| 1.05 B (step 1,000) | 8.95% | — |
| 5.24 B (step 5,000) | 21.99% | **2.80%** (B2-final, 5.0 B) |
| 50.3 B (step 48,000) | 44.35% | — |
| static-depth OLMo-2 baseline, 50.3 B | 35.25% | — |

It also pins the reference batch **exactly**. The static-depth rows have unambiguous
`effective_params` (1,073,874,944) and `FLOPs` (6.756e18 at step 1,000), and `F = 6ND` gives
`D = 1,048,576,000` — i.e. **1,048,576 tokens/step**, 1,024 sequences × 1,024 tokens, world size 64.
That is the measurement behind the "64× batch" figure in `../../recipe_sweep_findings.md`.
